# 截图功能开发计划（feat-screenshot）

> 状态：**已确认（2026-10-01）**——方案 C（Zviber 深色磨砂），并按要求做双主题适配：
> 工具条调色板随面板主题切换（nocturne 琥珀 / mica 蓝，浅色稿见 `shot-c-mica.html`）；
> 热键**默认为空、不启用**，不设托盘入口（需要时在设置窗录入）。
> 样式稿：`shot-a-qq.html` / `shot-b-lite.html` / `shot-c-nocturne.html` / `shot-c-mica.html`（浏览器可直接打开）。
> 实现预览（真实桌面渲染）：`impl-preview-nocturne.png` / `impl-preview-mica.png`。

## 一、目标

为 Zviber 增加 QQ 风格截图：可配置全局热键（**允许为空**）→ 全屏灰罩 → 框选 →
标注（矩形 / 椭圆 / 文字，文字支持选色与**反色**）→ 完成（复制 / 保存）、
**钉到桌面**（可拖拽、双击关闭）、**截长图**。

成功标准 = 第七节验证清单全部通过。

## 三、交互流程

1. 按热键（默认建议 `Ctrl+Shift+A`，设置窗可改、可清空；空 = 禁用热键）。
2. 全屏灰罩出现（十字光标）。拖拽框选；`Esc` 退出；选区可用 8 手柄或整体拖动调整。
3. 工具条：矩形 / 椭圆 / 文字 / 撤销 ｜ 长图 / 钉住 / 保存 / 复制 ｜ ✕取消 / ✓完成。
   激活绘图工具时弹出二级条：6 色 + 字号 S/M/L + 「反色」开关。
4. 完成 / 复制 = 入剪贴板并关闭；保存 = 存 PNG。
5. 钉住 = 当前选区（含标注）生成无边框贴图窗：挂桌面带、可拖拽、双击关闭、不持久化。
6. 长图 = 进入滚动捕获模式（见五.6），结束后导出长 PNG。

## 四、界面方案（三选一，等确认）

- **方案 A · QQ 经典深色**：深灰半透明工具条、蓝色高亮、纯图标。学习成本最低。
- **方案 B · 浅色极简**：白色工具条 + 图标带文字（Snipaste/PixPin 风），工具名一目了然。
- **方案 C · Zviber 深色磨砂**：与面板 nocturne 同源（`#1b1d24` + 琥珀 `#e8a33d`），整体感最强。

## 五、技术设计

1. **模块划分**（平铺、一个模块一个职责）：
   - 新增 `screenshot.py`：截图会话——遮罩窗 `ShotOverlay`、选区与手柄、标注模型、工具条、导出。
   - 新增 `pinshot.py`：钉图窗 `PinWindow`（挂桌面带复用 `boxes.pin_to_desktop`）。
   - `app.py`：`SettingsDialog` 加「截图快捷键」行；`main.pyw`：注册全局热键 + 托盘不动。
   - 不碰 `boxes.py` / `calendar_data.py` 逻辑。
2. **全局热键**：ctypes `RegisterHotKey`（用户态、不占钩子线程）+ `QAbstractNativeEventFilter`
   收 `WM_HOTKEY`。`cfg['shot_hotkey']` 存 QKeySequence 可移植字符串，**空串 = 不注册**；
   设置窗修改后即时注销重注册；注册失败（被占用）在设置窗提示。录入用 `QKeySequenceEdit` + 「清空」按钮。
3. **遮罩与多屏**：一个无边框顶层窗（`Frameless | Tool | StaysOnTop`）覆盖
   `QGuiApplication.virtualGeometry()`；开会话时逐 `QScreen.grabWindow(0)` 拼物理像素底图；
   窗口逻辑坐标 → 图像坐标按各屏 `devicePixelRatio` 换算（打包已有 DPI manifest，
   源码运行由 Qt 自设感知——**两条路都要测**）。
4. **标注模型**：`shapes` 列表（rect / ellipse / text × 颜色 × 字号 × invert），
   `QPainter` 画在底图副本上；撤销 = pop；导出 = 裁剪选区后矢量重绘一遍，保证导出清晰。
5. **文字工具**：点击落点出内联 `QLineEdit`（透明底、当前色、当前字号），回车/失焦入 shapes。
   「反色」= 文字下垫一个当前色色块、字色反为白/黑（按色块亮度取对比色）。
6. **截长图（MVP，呈现权衡）**：
   - 方案甲（选这个）：进入长图模式后程序向选区中心 `SendInput` 发滚轮事件，定时抓选区帧，
     纵向灰度条纹相关性匹配去重拼接，`Esc`/`✓` 手动结束导出（QQ/PixPin/ShareX 同款思路）。
   - 方案乙（不做）：用户逐屏手动截、程序负责叠——体验差。
   - **已知边界**：不响应滚轮的自绘窗口、页面动画/视频、懒加载会拼错；v1 只做纵向、
     不做自动停止；拼接受损时提示「请分段截取」。
7. **钉图**：`PinWindow` = `Tool` 无边框窗，贴图 + 细边框阴影；整窗可拖；
   双击关闭（QQ 行为）；`pin_to_desktop` 挂带免疫 Win+D；不持久化（进程退即消失，与 Snipaste 一致）。
8. **设置窗**：新增一行「截图快捷键」；允许留空，重开窗口仍是空（**不拿默认值兜底**，与时间框同约定）。

## 六、本期不做

马赛克、箭头、序号标注、OCR、GIF/录屏、放大镜、贴图持久化与多贴图管理、托盘「截图」菜单项。
（热键为空时暂无其他触发入口——若要托盘入口，确认样式时一并说。）

## 七、验证清单

- 热键：设置 / 修改 / 清空即时生效；与被占用键冲突有提示；空热键启动无注册无报错。
- 框选：100% / 125% / 150% DPI 下导出像素准确；双屏（不同缩放）跨屏框选。
- 标注：矩形 / 椭圆 / 文字 / 撤销；反色文字导出 PNG 与屏显一致。
- 钉图：拖拽、双击关闭、Win+D 后仍在、被应用窗压住可正常点回。
- 长图：浏览器长页拼接无明显错位；Esc 结束；失败有提示。
- 完成 / 保存：剪贴板可粘贴到微信 / 画图；保存的 PNG 可打开。
- 回归：`ZVIBER_SHOT` 自检不受影响；格子双击显隐与截图会话互不干扰。

## 八、里程碑

1. M1 遮罩 + 框选 + 完成/保存（最小闭环）→ 验证：DPI、双屏像素准确
2. M2 标注三件套 + 颜色/反色 + 撤销 → 验证：导出与屏显一致
3. M3 钉图 → 验证：拖拽 / 双击 / 挂带
4. M4 长图 MVP → 验证：浏览器长页
5. M5 热键 + 设置行 + 打磨 → 验证：冲突 / 空值 / 重注册

## 九、坑位备忘（承接 AGENTS.md）

- ctypes 函数全部显式声明 `restype`/`argtypes`（SendInput、RegisterHotKey、GetMessageW…）。
- 回调/钩子线程里绝不碰 Qt 对象。
- 槽函数未捕获异常靠 `_debug_excepthook` 兜底，新增槽同样适用。
- 遮罩窗不能用 `WA_TranslucentBackground` 整窗透明做遮罩（ClearType 发灰）——
  用 `QPainter` 在半透明黑上「擦」出选区镂空即可（自绘，不受影响）。
