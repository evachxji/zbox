# Zviber 桌面日历面板

「格子」风格的 Windows 桌面日历面板：**日历 + 待办** 一体的悬浮小面板，Win7 / Win10 / Win11 通用。

## 功能

- **悬浮面板**：无边框圆角、默认置顶、可拖动，停靠桌面右下角，位置自动记忆
- **固定（图钉）**：标题栏图钉按钮三档循环 —— 未固定（可拖动）→ 钉在桌面（不可移动、可被其它窗口覆盖）→ 始终置顶（不可移动），档位自动记忆
- **日历 tab**（默认）：顶部时钟 + 倒计时（午休前「距午休」→ 午休中「距上班」→ 之后「距下班」，休息日不显示）；周一起始月视图，双休着色、法定节假日「休」/调休「班」角标、农历与节日副标题、滚轮翻月、「今日」一键回当月
- **待办 tab**：双击空白处（或点底部提示条）新建待办；左侧 checkbox 勾选即完成，置灰 + 删除线并沉到列表底部，取消勾选回到顶部；右键条目可编辑/删除；文本过长自动折行占多行
- **截止日期 tag**：条目右侧显示截止情况 —— 逾期「逾期 N 天」（标红）/ 当天「今天」/ 一周内「还剩 N 天」/ 更远只显示 `M-d`
- **双栏模式**：设置窗口开启，左日历右待办同屏显示
- **设置窗口**：标题栏 ⚙ 弹出无边框设置窗口（主题/双栏/午休与下班时间/开机自启/节假日数据），非模态，改动即时生效
- **三档主题**：设置窗口切换 —— 深色 / 浅色 / 跟随系统（读 Windows「应用模式」，系统里改了会自动跟随），自动记忆
- **节假日数据**：内置 2025/2026 国务院官方调休安排；设置窗口「节假日」一栏可联网更新（timor.tech API）或离线导入 jiejiariapi.com 的年份 JSON（内网可用，窗内附分步说明）
- **系统集成**：开机无感自启（静默运行）；桌面右键菜单一键开关（**只在通过安装包安装后才会有**）；可打包为单文件 exe 安装包分发

## 快速开始（双击即可）

根目录下两个脚本，双击运行，不用敲命令行：

| 脚本 | 作用 |
| --- | --- |
| `run.cmd` | 启动面板；已在运行则切换显示 / 隐藏。缺 PyQt5 时会询问是否自动安装 |
| `build.cmd` | 一键打包出 `dist\ZviberPanel.exe`（本身即安装包）。缺依赖时会询问是否自动安装 |

两个脚本以 GBK 编码保存并自带 `chcp 936`：中文提示在 cmd 下不会乱码，Win7 同样适用。
**改脚本时请勿另存为 UTF-8**，否则双击后提示会变成乱码。

## exe 安装包（推荐给普通用户）

无需 Python 环境，单文件分发。双击根目录的 `build.cmd` 即可，或命令行构建：

```bat
python build.py        :: 构建，产物为 dist\ZviberPanel.exe（本身即安装包）
```

把 `ZviberPanel.exe` 发给他人，双击打开深色主题安装向导：

- **安装范围**：仅当前用户（默认 `%LOCALAPPDATA%\Programs`，免管理员）/ 此计算机（默认 `Program Files`，UAC 提权）
- **安装位置**：可修改，实时显示所需空间与所选磁盘可用空间（仅允许空/新文件夹，防止卸载误删）
- **附加选项**：桌面右键菜单、开机自动启动；安装过程有进度条

安装后出现在 Windows「设置 → 应用 → 安装的应用」列表（卸载项写入注册表），
可从那里直接卸载，也可用托盘菜单「卸载 Zviber」（该项只在已安装时出现）——运行中的面板会被自动请退。
卸载只移除程序与系统集成，待办与配置（`%APPDATA%\ZviberPanel\`）保留。

> 构建说明：PyInstaller 6.x + Python 3.9+ 打出的 exe 支持 Win10/11；
> Win7 需用 Python 3.8 + `PyInstaller==5.13.*` 构建。

## 运行（源码方式）

双击根目录的 `run.cmd` 即可（缺 PyQt5 会提示自动安装），或命令行：

```bat
pip install PyQt5
python install.py        :: 源码方式开启开机自启（HKCU 免管理员；右键菜单只在 exe 安装后才有）
pythonw main.pyw         :: 或直接启动
```

卸载：`python install.py --remove`

## 兼容性说明

- 基于 PyQt5（Qt 5.15）：Win7 / Win10 / Win11 均支持
- Win7 部署：安装 Python 3.8.x（最后一个支持 Win7 的版本）+ `pip install "PyQt5==5.15.*"`
- 数据存放 `%APPDATA%\ZviberPanel\`：`config.json`（主题/位置/模式）、`todos.json`（待办）、`holidays.json`（导入的节假日）
- 其余年份无官方调休数据时，仍显示双休与农历节日，仅不标「休/班」角标

## 自检

```bat
set ZVIBER_SHOT=designs\verify && python main.pyw
```
导出两主题 × 日历/待办/双栏截图到指定目录后自动退出。
