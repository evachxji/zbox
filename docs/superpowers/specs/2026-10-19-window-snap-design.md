# 截图窗口套选设计

日期：2026-10-19

## 目标

截图会话进入空闲态后，自动识别鼠标下最上层的真实程序窗口：

- 悬浮时显示该窗口的完整可见外框轮廓。
- 原地单击时把选区直接套到该窗口，进入现有标注态。
- 双击时直接套选、复制到剪贴板并退出截图。
- 原有按住拖拽自由框选、框选后标注、保存、钉图和长图能力保持不变。

## 非目标

- 不实现子控件级套选，例如只选浏览器网页内容区、设置页某个按钮或输入框。
- 不改变窗口背后的冻结截图来源；窗口套选只改变选区来源。
- 不改变钉图编辑模式、长图模式和工具条按钮。
- 不增加新的设置项或翻译文案。

## 方案

采用 Win32 顶层窗口探测：

1. 沿系统 Z 序从最上层向下查找鼠标所在位置的窗口。
2. 跳过本进程窗口、不可见/禁用窗口、透明穿透层、桌面壳层、任务栏、DWM 隐藏窗口和无效尺寸窗口。
3. 命中后取顶层根窗口，优先通过 `DwmGetWindowAttribute` 的
   `DWMWA_EXTENDED_FRAME_BOUNDS` 获取不含系统投影的可见外框；调用失败时回退
   `GetWindowRect`。
4. 将 Win32 屏幕坐标换算到 `ShotOverlay` 本地坐标，并裁剪到虚拟桌面范围内。

不采用 `WindowFromPoint`，因为它会先命中截图遮罩自身；不采用 Qt 窗口列表，因为它无法可靠识别浏览器、资源管理器等非 Qt 程序。

## 交互状态

### 空闲态悬浮

- 仅在 `idle`、未拖拽、未编辑文字时探测鼠标下的窗口。
- 命中有效窗口时保存悬浮矩形并重绘 2px 主题色轮廓。
- 移出窗口或没有命中时清除轮廓。
- 轮廓只作为提示，不提前创建选区、不显示工具条。

### 按下与松开

- 左键按下仍进入现有创建选区流程，并记录按下位置及当下命中的窗口句柄/外框。
- 移动后选区任一边达到 `MIN_SEL` 时，视为用户主动自由框选。
- 松开时选区小于 `MIN_SEL`、按下时命中过窗口，且松开位置仍在该窗口外框内，则使用按下时记录的外框进入 `ready`。
- 未命中窗口的短点击保持 `idle`，仍可按原方式拖拽框选。

### 双击

- 第一次点击命中的窗口后进入 `ready`。
- 第二次点击由现有 `mouseDoubleClickEvent` 接住；当双击点仍在选区内时调用
  `_finish_copy()`，复制选区并关闭截图会话。
- 双击空白区域不触发完成，避免误复制。

## 组件边界

改动集中在 `screenshot.py`：

- 新增纯 Win32 探测辅助函数，返回全局坐标窗口矩形；不依赖 `ShotOverlay` 实例，便于测试和复用。
- `ShotOverlay` 增加悬浮窗口矩形状态、悬浮刷新和清除逻辑。
- 鼠标移动、按下、松开、双击和重绘接入现有状态机。
- 长图的 `_find_wheel_target` 保持现有行为，避免改变滚轮目标选择。

`pinshot.py`、`transfer.py`、`video_*.py` 和面板 UI 不改动。

## 错误处理

- 任一 Win32/DWM 调用失败时只跳过本次窗口提示，用户仍可自由拖拽框选。
- 裁剪后为空或小于 `MIN_SEL` 的窗口不参与套选。
- 窗口在拖动过程中移动或关闭时，外框仍以按下时结果为准；松开位置已不在该外框内则按原有手动框选逻辑处理。

## 测试

新增 `tests/test_screenshot_window_snap.py`：

- 悬浮命中窗口时保存裁剪后的轮廓矩形，离开后清除。
- 短点击窗口时自动进入 `ready`，选区等于窗口外框。
- 超过阈值的拖拽继续得到手动框选，不覆盖为窗口矩形。
- `ready` 态在选区内双击会调用完成复制。
- 无窗口命中时短点击不产生选区。

验证命令：

```text
python -m unittest discover -s tests -v
```

同时运行中英文截图自检，确认新增轮廓不会破坏现有 59 个场景：

```text
set ZBOX_SHOT=designs\verify-zh && set ZBOX_SHOT_LANG=zh-CN && python main.pyw
set ZBOX_SHOT=designs\verify-en && set ZBOX_SHOT_LANG=en-US && python main.pyw
```
