# PC 与 Android 中英双语设计

## 目标

为 PC 端和 Android 端增加简体中文与英文两种界面语言。首版覆盖所有用户可见文案，包括主界面、设置、按钮、弹窗、错误提示、安装与卸载向导，以及辅助功能文案。

## 语言规则

PC 与 Android 使用相同的语言优先级：

1. 用户主动保存的语言设置。
2. PC 安装向导写入的此计算机默认语言；Android 无这一层。
3. 操作系统语言检测结果。

检测规则：

- 系统语言为中文时使用简体中文。
- 系统语言为英文或其他可识别语言时使用英文。
- 系统语言无法识别时使用简体中文。

PC 安装向导首屏默认选中检测结果，并允许在安装前切换。安卓首次启动使用检测结果，之后以用户设置为准。

## 实现方案

采用轻量、语义化的本地字典，不引入 Qt Linguist 构建链或 Android AppCompat per-app language 依赖。

PC 端：

- 新增 `i18n.py`，提供语言状态、系统语言检测、缺省值解析和 `t(key, **kwargs)`。
- 中文与英文词典分别放入独立模块，由 `i18n.py` 汇总，避免主逻辑与大量文案混在一起。
- 所有用户可见文案通过语义化 key 获取；协议字段、文件名和用户数据保持语言无关。
- 缺少翻译 key 时回退到中文并保留可诊断日志，不让界面直接显示 key。

Android 端：

- 新增统一的 `AppStrings` 语言对象，所有 Compose 界面和传输核心的状态文案通过当前语言获取。
- 当前语言保存在 SharedPreferences；切换后通过 Compose 状态立即重组，不重启 Activity。
- 协议字段、设备信息、文件路径和历史文件记录不翻译。
- 运行期错误在展示层按当前语言生成，不把最终显示文案作为长期历史数据冻结。

## PC 设置

设置窗口保持现有即时保存模式，内容顺序调整为：

1. 现有设置项。
2. 版本号与“检查更新”。
3. 分割线。
4. 最底部“语言”下拉框。

下拉项为“简体中文”和“English”。切换后立即写入用户配置，但当前窗口不重建。程序弹出提示“语言更改将在重启后生效”，提供“立即重启”和“稍后”：

- “立即重启”先正常退出当前实例并完成现有清理，再以相同启动方式重新打开程序。
- “稍后”保留当前界面语言，直到用户手动重启。

## PC 安装与卸载

安装向导首屏增加“语言 / Language”下拉框，默认值来自系统语言检测。切换后整个向导立即切换语言。选择结果通过提权参数传递，UAC 重启后不丢失。

向导移除“安装范围”区域，始终按所有用户安装：

- 默认安装目录为 `Program Files\zbox`。
- 保留安装位置和附加选项。
- 点击安装时自动请求管理员权限。
- 安装成功后，将语言写入 HKLM 的 Zbox 安装信息，作为此计算机默认语言。

实际安装前清理已有 Zbox 安装：

1. 通知正在运行的 Zbox 退出并等待文件释放。
2. 检查 HKCU 与 HKLM 中明确属于 Zbox 的卸载、开机自启、右键菜单等注册信息。
3. 检查注册表记录的安装目录、默认当前用户目录和 `Program Files\zbox`。
4. 仅当目录中确认存在 `zbox.exe` 时删除该程序目录。
5. 清理完成后安装新的所有用户版本。

清理只触碰明确属于 Zbox 的注册信息和程序目录，并保留 `%APPDATA%\zbox` 用户数据。本次新清理流程不主动搜索或处理 `zviber`；已有 `zviber` 兼容代码保持原样。旧进程拒绝退出或旧文件无法删除时，安装明确失败并保留现有安装，不带残留继续覆盖。

安装向导、提权安装实例和卸载向导的标题、说明、按钮、进度文字及错误提示全部支持中英文。卸载向导从用户语言、机器默认语言、系统语言的同一优先级链中取语言。

## Android 导航与设置

新增底部 `NavigationBar`，包含“传输”和“设置”两个 tab，默认进入“传输”。本机别名继续留在传输首页，设置页首版只提供语言选择。

设置页使用“简体中文 / English”两个单选项。切换后立即保存并刷新全部界面，包括：

- 传输首页与附近设备。
- 传输记录与操作菜单。
- 接收、发送来源等弹窗。
- 按钮、空状态、错误和状态提示。
- `contentDescription` 等辅助功能文案。

应用名保持品牌名 `Zbox`。

## 验证

- 单元测试覆盖 PC 语言优先级、系统语言识别、缺失翻译回退和格式化文案。
- UI 测试覆盖 PC 语言项位置、独立分割线、重启提示和两种选择行为。
- 测试安装前清理只匹配 Zbox，不删除包含用户数据的目录，并能识别 HKCU 与 HKLM 安装。
- 分别以中文、英文运行 PC 全界面截图自检，检查面板、设置、弹窗、传输和视频页面无截断、漏翻或布局溢出。
- 运行 `python -m unittest discover -s tests -v` 和 `python transfer_selftest.py`。
- Android 执行 `gradlew.bat assembleDebug`，手工验证底部导航、首次语言检测、设置页即时切换，以及主要弹窗和错误提示跟随语言。
- 手工走查安装、UAC 提权、旧安装清理、启动和卸载流程的中英文文案与数据保留行为。
