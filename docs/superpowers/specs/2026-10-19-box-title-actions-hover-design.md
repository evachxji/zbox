# 桌面格子顶部操作图标悬停显隐

## 目标

桌面格子顶部栏右侧的“收起 / 锁定 / 菜单”三个图标默认不可见。鼠标进入顶部栏时淡入，离开顶部栏时淡出；其他顶部栏内容、格子拖动和收起态悬停预览保持现有行为。

## 交互

- 三个图标作为一组控制，共用一个透明度动画。
- 鼠标进入顶部栏后约 140 ms 淡入，离开顶部栏后约 180 ms 淡出。
- 图标始终保留布局宽度，淡入淡出期间标题和图标位置不发生变化。
- 完全透明时，三个按钮不接收鼠标事件，避免误点不可见控件。
- 菜单打开期间图标保持可见；菜单关闭后，根据鼠标是否仍在顶部栏内决定是否淡出。
- 收起态原有的“悬停标题栏临时展开预览”逻辑保持不变。
- 锁定、收起和菜单操作仍沿用现有行为，不新增持久化状态或配置项。

## 实现边界

改动集中在 `boxes.py` 的 `BoxWindow` 顶部栏：

- 将三个 `QToolButton` 放入独立的操作区控件，由整组共享 `QGraphicsOpacityEffect` 和单个 `QVariantAnimation`。
- 顶部栏安装鼠标进入/离开事件处理；操作区自身悬停也视为顶部栏悬停，并兼容从名称区移动到按钮区。
- 鼠标事件穿透只作用于完全透明的按钮组，不影响顶部栏拖动、双击收起和内容页交互。
- 不调整格子主题、标题布局尺寸或现有菜单/锁定/收起逻辑。

## 验证

- 新增或扩展 UI 回归测试，验证默认透明度为 0、进入顶部栏后目标透明度为 1、离开后回到 0，以及透明状态不接收按钮点击。
- 运行 `python -m unittest discover -s tests -v`。
- 运行截图自检，检查深色/浅色工作区中普通、收起及悬停顶部栏场景的布局稳定性。
- 手工验证拖动顶部栏、双击收起、锁定、菜单打开关闭，以及收起态悬停预览没有回归。
